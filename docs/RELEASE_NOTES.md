## Perf Saver

Optimiseur Windows pour le jeu : ferme ce qui est inutile, met en pause les services superflus, passe l'alimentation en hautes performances et donne la priorité à ton jeu. Tout est réversible.

### Installation
1. Télécharge **PerfSaver-Setup-x.y.z.exe** ci-dessous et lance-le.
2. Si Windows SmartScreen s'affiche : *Informations complémentaires* → *Exécuter quand même* (le logiciel n'est pas encore signé).
3. Accepte la demande administrateur (nécessaire pour gérer les services et les priorités).

Version sans installation : **PerfSaver-portable-x.y.z.zip** (garde les deux fichiers ensemble).

Configuration requise : Windows 10 ou 11 64 bits, runtime Microsoft Edge WebView2 (déjà présent sur Windows 11).
